# 任务 3 · 甲方点名要看的场景渲染

甲方原话：*"听说现在模型能直接渲染火箭发射、火山喷发，你让它们给我看看，哪个好看。"*

所以这一题不考工程，考**一眼**。20 分钟。

## 二选一

- **火箭发射**：起飞、越飞越快、级间分离、尾焰和马赫环
- **火山喷发**：岩浆喷柱、碎屑下落、烟尘扩散、熔岩流

## 必须做到

1. 单个 HTML（配一两个 js 文件也行），**打开就能跑**，不许构建
2. 屏幕角落显示实时 FPS
3. 至少 3 个可调参数（比如推力、喷发强度、粒子数），改了立刻能看到变化
4. 一个重置按钮
5. **打开后 10 秒内必须出现最精彩的那一幕**，不许等人操作才好看

## 一条特殊的硬要求：物理自检

页面里（或 README 里）写 100 字以内，说清楚你实现里下面这几个量是怎么变的：

- 火箭：推力、剩余质量、加速度三者关系；什么时候加速度最大
- 火山：喷发初速、重力、最高点高度三者关系

**这不是考物理，是防"漂亮但假"。** 一个只会调参数的模型写不出这段；一个真懂的模型 30 秒就能写。

## 硬约束

- 全部相对路径，不许 `C:\...` 或 `file://`
- 不许下载外部模型/贴图当主体（程序化生成，CDN 引 three.js 可以）
- 不许把参数写死后假装可调

## 你会怎么被评

甲方只看两件事：**好不好看**、**动不动**。评分人会先看这两件，再看那段物理自检对不对。
如果画面惊艳但物理自检胡扯，这一题按 3 分算，不按 5 分。
