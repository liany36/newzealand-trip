# 任务 3 · 火箭发射

双击 `index.html` 或者放到任意静态服务器上打开即可（three.js 0.160 从 CDN 加载）。打开后会自动点火：约 1.2 秒起飞，约 5.6 秒一级关机，约 6 秒级间分离，约 6.5 秒二级点火，飞行约 34 秒后自动重播。

- 右上角有 4 个滑块，拖动立即生效：一级推力（同时改变耗油速度，推力低于重力时火箭不会起飞）、粒子上限、马赫环亮度、时间流速。下面还有"重置"按钮。
- 左上角显示实时 FPS 和遥测（推力、质量、a = T/m − g、峰值加速度）。
- 在网址后加 `#t=6` 可以直接跳到第 6 秒（分离那一幕）。

## 物理自检（100 字内）

推力 T 由滑块给定，燃料消耗率 ṁ = T / vₑ，剩余质量 m 随时间线性下降，加速度 a = T/m − g（忽略空气阻力）。每一级燃烧时 a 不断增大，在关机前一刻达到最大。分离后抛掉一级干重，二级的 a 从较低值重新增大，全程最大值出现在二级关机前。
