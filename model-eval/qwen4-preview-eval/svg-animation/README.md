# 附加题 D · 三个内联 SVG 动画

线上入口：<https://mrlian.ai/model-eval/qwen4-preview-eval/svg-animation/>
（对比表首页 <https://mrlian.ai/model-eval/qwen4-preview-eval/> 表下的"附加题 D"一节也有直达链接。）

## 这里面是什么

| 文件 | 是什么 | 循环 |
|---|---|---|
| `index.html` | 展示页：三张带静帧预览的卡片，可直接内嵌播放、全屏打开、下载 HTML | — |
| `pelican-bike.html` | 鹈鹕骑自行车。海岸公路四层视差；脚始终踩在踏板上、双骨 IK 解膝盖；车轮转速与地面滚动严格相等 | 20 秒 |
| `croc-watch.html` | 鳄鱼修机械表。四齿轮真实啮合（40/28/20/15 齿，相邻反向、转速与齿数成反比）；摆轮擒纵；螺丝刀尖全程贴着零件 | 24 秒 |
| `octopus-clock.html` | 章鱼给座钟上油。八条腕分工；油滴攒大→脱落→加速下落→摊开；钟摆周期符合 2π√(L/g) | 30 秒 |
| `shots/*.jpg` | 三张静帧预览图，只给展示页用；动画本身不含任何位图 | — |

三个动画都是**单文件、打开即播**：内联 SVG + 原生 JS，零依赖、零网络请求、零位图、零外部字体。
每个文件只有一条 `requestAnimationFrame` 时间轴，所有关节/齿轮/钟摆的角度都是同一个时间变量的纯函数；
每个重复动作的周期都整除循环长度，所以循环首尾的姿态和速度都接得上。

页面左下角的工具栏：暂停/播放（空格）、相位滑杆（定格循环内任意一秒）、0.5×/1×/2× 倍速、
下载当前姿态的 SVG、复制当前帧 SVG 源码、隐藏工具栏（按 `H`）。
被展示页内嵌播放时（URL 带 `?embed=1`）工具栏默认收起，画面更干净，按 `H` 或点左下角小按钮可调出。

## 机构参数（改这些数，画面会跟着变）

参数都集中在各文件顶部的 `PARAMS`：

- **鹈鹕**：`chainringTeeth: 32`、`cogTeeth: 16`（齿比 2:1）、`wheelRadius: 95`、`crankLength: 55`、
  `thigh/shin: 105`、`crankRPM: 60`、`bobAmp: 7`（起伏:踩踏 = 2:1）、`pouchLag: 0.7`、四层视差系数与整数重复数。
- **鳄鱼**：`module: 6`、`teeth: [40, 28, 20, 15]`、`barrelTurns: 1`、`balancePeriod: 0.6`、`balanceAmp: 0.7`、
  `toolVisits: 3`。齿轮中心距 = 节圆半径之和；啮合相位按"接触线上主动轮齿对从动轮齿槽"解出，所以齿不穿插。
- **章鱼**：`g: 980`、`pendulumLength: 620.6`（→ T = 5.000 秒，6 整周期/循环）、`pendulumAmp0/Dip`、
  `oilPeriod: 6`、`oilGravity: 900`。八腕分工写在 `ARMS` 里，每条腕的尖端目标都是时间的函数。

node qa/verify.mjs                    # 自动起本地服务，跑完关掉

零第三方依赖：只用 Node 内置模块 + 本机 Chrome/Edge 的 CDP。覆盖 80 项检查：

- 对比表首页：附加题 D 的 4 个入口存在、14 个链接全部可达、无横向溢出、控制台干净；
- 展示页：三张预览图加载、内嵌播放真的在走、同时只播一个、切换不堆积 iframe、停止回到静帧、
  返回链接可达、手机 390×844 下无溢出且画面保持 16:9、手机也能内嵌播放；
- 三个动画各自：打开即播、工具栏齐全、1 秒像素差、暂停冻结/恢复续走、相位滑杆定格、2× 倍速、
  复制当前帧（真实鼠标点击后读剪贴板核对；剪贴板不可用时核对兜底弹窗）、下载生成合法 `image/svg+xml`、
  工具栏隐藏/恢复/快捷键、收起态不遮挡画面、空格切换、`?embed=1` 行为、
  1024×768 / 390×844 / 1920×1080 三种视口铺满且工具栏在屏内、循环首尾截图差异 < 3%、帧率 ≥ 55、控制台干净。

截图落在 `qa/shots-verify/`（已 gitignore）。最近一次运行：**80 项全部通过**。

题目本身的机构断言（齿比、滚动=弧长、钟摆周期、接触距离等 30 项）在出题方的 harness 里跑，
本次结果也是全绿；那个 harness 不属于这个网站仓库，所以没有放进来。

## 已知不足

- 擒纵机构是"齿尖扫过叉瓦"的示意画法，不是真实瑞士杠杆式的锁接与释放。
- 章鱼腕是带粗细变化的贝塞尔曲线带，不是肌肉体积模拟；吸盘单排骑在中心线上。
- 鹈鹕喉囊形变是参数化曲线，不是物理模拟。
