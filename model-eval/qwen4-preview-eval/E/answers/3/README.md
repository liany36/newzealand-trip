# 任务 3 · 火箭发射 · 实时渲染

## 怎么跑

双击 `index.html`，或丢到任意静态服务器（本目录含 `three.min.js` 与 `scene.js`，全部相对路径，无构建、无外部请求）。打开即自动点火，无需任何操作。

## 要求对照

- 打开 10 秒内出现最精彩一幕：0.5 s 点火 → 约 6.5 s 一级燃尽 → 级间分离（火花 + 空壳翻滚坠落 + 二级点火），全程自动。
- 左上角实时 FPS；右下角物理自检。
- 三个实时可调参数：推力倍率（0.5–2×）、尾焰粒子数（500–6000）、时间流速（0.25–2×），拖动即生效。
- 「重置发射」按钮回到点火前状态。
- 全部几何程序化生成（圆柱/圆锥/盒体 + 粒子系统），无外部模型/贴图。

## 物理自检（100 字内）

推力 F 恒定，质量 m = 干重 + 剩余燃料随燃烧线性减小，加速度 a = F/m − g 持续增大；每级燃料将尽时 m 最小、该级加速度最大，全程峰值在二级燃尽瞬间。分离抛壳使 m 骤降，但二级推力小，a 先回落再爬升。尾焰膨胀随气压 exp(−h/H) 降低而增大，马赫环间距变宽。

数值核对（默认参数）：一级点火 a≈6.7 m/s²，燃尽瞬间 a≈51.5 m/s²（该级峰值）；分离后二级点火 a≈9.6 m/s²，燃尽 a≈190 m/s²（全程峰值）。与遥测面板实时显示一致。
