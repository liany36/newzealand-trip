# 任务 3 · 火箭发射场景

## 怎么跑

双击 `index.html`。零构建、零外网依赖（`vendor/three.min.js` 本地引用）。
打开 1 秒内点火，约 2 秒离塔，约 8 秒一级燃尽并分离，10 秒左右二级已经爬到千米级高度——最精彩的那一段在头 10 秒内全部发生。

参数：**推力 / 粒子密度 / 燃耗率** 三个滑杆，拖动立刻改变物理与画面。
「重播」重置到点火前。右上角是实时 FPS，右下角是高度 / 速度 / 质量 / 加速度。

## 物理自检（97 字）

推力 T 恒定，质量 m 随燃料线性递减，阻力 ½ρC<sub>d</sub>Av² 随速度平方增长：
**a = (T − mg − ½ρC<sub>d</sub>Av²) / m**。
分母一直在掉、分子基本不变，所以 **a 单调上升，在燃料耗尽那一瞬间最大**（默认参数下约 32 m/s²，起飞时约 20 m/s²）。
起飞质量 1500 kg，重力 14.7 kN；**把推力拉到 14.7 kN 以下火箭不离台**——这条也能在页面上直接验证。

## 实现要点

- 单 HTML + 本地 three.js r128，无打包。
- 粒子用自定义 `ShaderMaterial` + `gl_PointSize`，CPU 端双缓冲池（热焰 7000 + 烟 5000），加性/普通混合分两套。
- 尾焰是三层叠加：加性圆锥核心 + 外层橙焰 + 沿轴线排布的马赫环精灵（低空、高速、大气密度足够时才出现，高空中随 ρ 衰减自动消失）。
- 贴图全部用 `canvas` 程序化生成（径向渐变 / 菱形），没有任何外部图片。
- 相机带滞后跟随 + 推力震动 + FOV 随速度加宽，用来制造加速感。
